The new [Compare page](/layer2s/compare) charts any number of Layer 2s side by side on up to four charts: Value Secured, Activity, Costs and Data posted. Ethereum can be added as a baseline. The whole view is kept in the URL, so you can share a comparison with a link. Compare is also reachable from the search bar, the metric pages and project pages.
