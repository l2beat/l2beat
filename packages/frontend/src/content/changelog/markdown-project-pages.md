---
title: "Project pages are now available as markdown"
summary: "Scaling, data availability, privacy, interop and ZK catalog project pages can be read as markdown."
publishedAt: "2026-09-30T12:00:00.000Z"
---

Project pages are now available as plain markdown, so AI agents and LLM tools can read L2BEAT data without parsing HTML. Add `.md` to a project page URL, e.g. [/layer2s/projects/arbitrum.md](/layer2s/projects/arbitrum.md), or request the page with `Accept: text/markdown`.

Markdown is available for scaling projects, data availability layers, privacy protocols, interop protocols and tokens, and ZK catalog projects. All available pages are listed in [llms.txt](/llms.txt).
