---
title: "Introducing Ossification"
summary: "A new metric for how battle-tested the code securing each project is."
publishedAt: "2026-10-07T12:00:00.000Z"
---

The new [Ossification page](/ossification) measures how battle-tested the code securing each project is, based on an open dataset of EVM exploits. Every critical change resets the clock, and battle-tested exposure shows how much value the code secured while unchanged. Project pages show the details in their Updates section. Read the [research article](/publications/ossification) for the methodology.
