### Enforcement

Intents Technology Ltd. (British Virgin Islands) [screens](https://docs.near-intents.org/security-compliance/risk-and-compliance) the addresses in every swap quote against its own AML database, Binance AML, AMLBot, PureFi and TRM Labs. It checks each deposit again before crediting it. Its [terms](https://docs.near-intents.org/security-compliance/terms-of-service) let it delay, block or freeze bridged funds. Market makers pass KYB, end users swap without an account. Zcash's shielded pool, between the two swaps, checks nothing. The screening service is closed. No rule says which match blocks a swap.

### Data access

The listed vendors can receive each quote's addresses, before the swap exists. The terms let the operator collect IP and wallet addresses. It takes law enforcement requests through a portal.
