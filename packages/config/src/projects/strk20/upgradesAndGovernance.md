The governance multisig, a 7/12, holds the governance, security and upgrade roles of the pool and the anonymizer, and can replace either's code at once. The app multisig, a 2/4, owns a delayed executor that can upgrade both behind a one-day delay. Both multisigs hold the pool's app role, which sets the fee, the fee collector, the proof validity window and which DeFi helpers need screening. The security governor role, held by the governance multisig, can replace the auditor and screener keys at once. Pausing the pool needs a role nobody holds, which the governance multisig can grant.
