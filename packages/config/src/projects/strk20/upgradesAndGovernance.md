A 7/12 multisig holds the pool's governance, security and upgrade roles and can replace the pool's code at once. It and a 2/4 multisig both hold the app role, which sets the fee, the fee collector, the proof validity window and which DeFi helpers need screening. The 2/4 also owns a delayed executor that holds the upgrade role behind a one-day delay. The security governor role, held by the 7/12, can replace the auditor and screener keys at once. Pausing needs a role nobody holds today, which the 7/12 can grant.

The anonymizer has no upgrade delay. A 1/3 multisig holds its governance and upgrade roles, and the 7/12 can upgrade it too.
