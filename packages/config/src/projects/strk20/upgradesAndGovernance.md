A 7/12 multisig holds the governance, security and upgrade roles of the pool and the anonymizer, and can replace either's code at once. A 2/4 multisig owns a delayed executor that can upgrade both behind a one-day delay. The 7/12 and the 2/4 both hold the pool's app role, which sets the fee, the fee collector, the proof validity window and which DeFi helpers need screening. The security governor role, held by the 7/12, can replace the auditor and screener keys at once. Pausing the pool needs a role nobody holds today, which the 7/12 can grant.
