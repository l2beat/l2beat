### Enforcement

The ASP may ask for a Proof of Association, which 0xbow's [separate app](https://tornado.0xbow.io) creates for funds that left Tornado Cash. Each pool accepts a private withdrawal only with a proof against the ASP's latest list, so the ASP can remove a deposit it approved earlier. Notes never change owner inside the pool, so a removal reaches the depositor alone. The contracts accept no second list and check no withdrawal address. The ASP's lists are public on IPFS.

### Access to private data

The ASP's review sees only the public depositing address.

### Proof of clean origin

A recipient reads the proof from the transaction and needs nothing from the user. It speaks for 0xbow's list alone. That list is also the set a withdrawal hides in, which 0xbow can shrink.
