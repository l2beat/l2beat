**Reproducibility note (private dependency).** This SP1 program is built from public source ([mantle-xyz/op-succinct](https://github.com/mantle-xyz/op-succinct/tree/v3.8.1-mainnet-mantle-arsia.1)), but the build pins the entire `revm` crate family — via `[patch.crates-io]` — to a **private** GitHub Security Advisory fork ([mantle-xyz/revm-ghsa-5vfr-x84h-hmvf](https://github.com/mantle-xyz/revm-ghsa-5vfr-x84h-hmvf) at rev `99707e9f`) that is not yet publicly disclosed. **A member of the public cannot currently reproduce this verification key** without access to that fork. L2BEAT obtained access to it and independently reproduced this key **byte-for-byte from source** — the rebuilt ELF is identical to the one committed in the release, and its printed vkey matches the on-chain value. It will become publicly reproducible once the GHSA is published. The steps below assume access to the private fork.

Prepare:

1. Install cargo make: `cargo install --debug --locked cargo-make`
2. Install sp1 toolchain v6.1.0: `curl -L https://sp1up.succinct.xyz/ | bash`, then `sp1up -v v6.1.0` (must match the workspace's `sp1-zkvm = "=6.1.0"` and the docker tag used below).
3. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/)
4. Access to the private [mantle-xyz/revm-ghsa-5vfr-x84h-hmvf](https://github.com/mantle-xyz/revm-ghsa-5vfr-x84h-hmvf) fork at rev `99707e9f21a7c32255c9072be25814ab1b8d913d`. This is a Mantle-internal GitHub Security Advisory (GHSA) fork of `revm` that is not yet publicly disclosed; the `Cargo.toml` at the tag below pins all `revm-family` crates to it via `[patch.crates-io]`. Contact Mantle for access, or wait for the GHSA to be published. A vendored path override will NOT reproduce — the vkey is sensitive to the Cargo source identity, so the dep must appear to Cargo as `git+https://github.com/mantle-xyz/revm-ghsa-5vfr-x84h-hmvf?rev=99707e9f…`.

Verify:

1. Checkout the correct tag in [mantle-xyz/op-succinct](https://github.com/mantle-xyz/op-succinct/tree/v3.8.1-mainnet-mantle-arsia.1) repo: `git checkout v3.8.1-mainnet-mantle-arsia.1`. Commit hash should be `c7a61629478fa8301cb745f415a866a486497e5d`.
2. Make the private revm fork available to Cargo under its pinned source id. One reliable path: clone the private repo locally, then seed cargo's git cache so a fetch of `git+https://github.com/mantle-xyz/revm-ghsa-5vfr-x84h-hmvf?rev=99707e9f…` resolves to it while preserving that source id.
3. Make sure docker is running by running `docker ps`.
4. From the `op-succinct` dir: `cargo run --bin config --release` to build the SP1 programs and generate and print verification key hashes. The `Aggregation Verification Key Hash` printed is this program hash.
