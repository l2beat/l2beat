Prepare:

1. Install sp1 toolchain v6.4.0: `curl -L https://sp1up.succinct.xyz/ | bash`, then `sp1up -v v6.4.0`
2. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/)
3. Install just [https://github.com/casey/just](https://github.com/casey/just)

Verify:

1. Checkout the correct tag in [mantle-xyz/op-succinct](https://github.com/mantle-xyz/op-succinct/tree/mantle-v1.6.1) repo: `git checkout mantle-v1.6.1`. Commit hash should be `8d280ded13f3fcba3d85fb6babedaf75cab5e9c0`.
2. Make sure docker is running by running `docker ps`
3. Delete the committed ELFs so that only rebuilt ones get hashed: `rm elf/aggregation-elf elf/range-elf-embedded`
4. From the `op-succinct` dir: `just build-elfs` to rebuild the SP1 programs in docker.
5. From the `op-succinct` dir: `just vkeys` to print the verification key hashes. This program hash is the `Range Verification Key Hash`.
