Regeneration steps are based on [this guide](https://github.com/fluentlabs-xyz/fluent-stf/blob/v1.0.9/README.md). The process is reproducible on a Linux x86_64 (amd64) machine.

1. Install prerequesits: `docker`, `python3`, `git`, `jq`.
2. Checkout correct branch in https://github.com/fluentlabs-xyz/fluent-stf/tree/v1.0.9: `git checkout v1.0.9`. Commit hash should be `2bb682552b130820d4ea22162e3205a1f572075a`.
3. Build Nitro program for the mainnet within docker: `make build-nitro-validator-docker NETWORK=mainnet`. This command will create `nitro-validator-mainnet.vkey` file with the program hash string.
