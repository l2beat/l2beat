Prepare:

1. Install `just`: `brew install just` (or `cargo install just`).
2. Install sp1 toolchain: `curl -L https://sp1up.succinct.xyz/ | bash`, then `sp1up`.
3. Install docker https://docs.docker.com/get-started/get-docker/
4. Install `lld` (required by the repo's `.cargo/config.toml`)

Verify:

1. Checkout the specific commit in [base/base](https://github.com/base/base) repo: `git checkout 09a973afe8467919370b90bc87ac1e7fde12c43b`. This commit lives on the untagged `mw2000/zk-plonk-update` branch.
2. Make sure docker is running: `docker ps`.
3. From the repo root: `just succinct vkeys` to build the range and aggregation SP1 ELFs (reproducible docker build, SP1 toolchain tag `v6.3.0` pinned in `etc/just/succinct.just`) and print their verification key hashes.
