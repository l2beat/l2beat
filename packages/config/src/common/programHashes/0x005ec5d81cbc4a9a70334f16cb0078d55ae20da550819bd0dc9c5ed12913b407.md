Prepare:

1. Install sp1 toolchain v6.4.0: `curl -L https://sp1up.succinct.xyz/ | bash`, then `sp1up -v v6.4.0` (must match the workspace's `sp1-zkvm = "=6.4.0"`).
2. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/)
3. Install just [https://github.com/casey/just](https://github.com/casey/just)

Verify:

1. Checkout the correct tag in [mantle-xyz/op-succinct](https://github.com/mantle-xyz/op-succinct/tree/mantle-v1.6.0) repo: `git checkout mantle-v1.6.0`. Commit hash should be `e2eab907bec58ece8ed2206d10f5fd131d864e40`. Unlike the previous `v3.8.1-mainnet-mantle-arsia.*` line, this release pins the `revm` crate family to the public [mantle-xyz/revm](https://github.com/mantle-xyz/revm) fork at tag `v107-mantle-arsia.1`, so no private dependency is required.
2. Make sure docker is running by running `docker ps`.
3. Delete the committed ELFs so that only freshly built ones can be hashed: `rm elf/aggregation-elf elf/range-elf-embedded`.
4. From the `op-succinct` dir: `just build-elfs`. This checks every tag-pinned git dependency against its remote (`verify-git-pins`) and then rebuilds `programs/range/ethereum` and `programs/aggregation` reproducibly with `cargo prove build --docker --tag v6.4.0` (image `ghcr.io/succinctlabs/sp1:v6.4.0`).
5. From the `op-succinct` dir: `just vkeys` (runs `cargo run --release --bin config` over the rebuilt `elf/*`) and prints the verification key hashes. The `Aggregation Verification Key Hash` printed is this program hash (stored on-chain as `aggregationVkey`). The [mantle-v1.6.0 release notes](https://github.com/mantle-xyz/op-succinct/releases/tag/mantle-v1.6.0) list the expected values.

Reproduced 2026-09-11 on Ubuntu 24.04 (x86_64) with SP1 v6.4.0 (`cargo-prove sp1 (f66b4bf 2026-08-12)`, docker image `ghcr.io/succinctlabs/sp1:v6.4.0`) at commit `e2eab907bec58ece8ed2206d10f5fd131d864e40`. The rebuilt `elf/aggregation-elf` (sha256 `d73f10ebd3f643f95cdaef8153d5f22fb5ad6be35ac55351383be5ef83807555`) is byte-identical to the committed one and hashes to `0x005ec5d81cbc4a9a70334f16cb0078d55ae20da550819bd0dc9c5ed12913b407`, matching `aggregationVkey()` on `OPSuccinctL2OutputOracle` (`eth:0x31d543e7BE1dA6eFDc2206Ef7822879045B9f481`).
