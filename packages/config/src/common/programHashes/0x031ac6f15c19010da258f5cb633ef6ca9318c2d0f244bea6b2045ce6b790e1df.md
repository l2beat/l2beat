1. Install [just](https://just.systems).
2. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/) and make sure it is running.
3. Check out the correct commit of the [optimism](https://github.com/ethereum-optimism/optimism) repo (tag `kona-client/v1.7.0-rc.2`): `git checkout 64b043ea5bbca9bc6e57e0f1c8df0404b4cf5f68`.
4. From the monorepo root run `just reproducible-prestate`. A single docker build produces both variants and prints their hashes; this prestate is the `kona-client-int` (interop) one.
