1. Install [just](https://just.systems).
2. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/) and make sure it is running.
3. Check out the correct commit of the [optimism](https://github.com/ethereum-optimism/optimism) repo (tag `kona-client/v1.9.0`): `git checkout 1286a886f0853e07503b46c2d6233b6a2f623286`.
4. From the monorepo root run `JUST_UNSTABLE=1 just reproducible-prestate` (the root justfile uses the unstable `[script]` attribute). A single docker build produces both variants and prints their hashes; this prestate is the `kona-client-int` (interop) one.
