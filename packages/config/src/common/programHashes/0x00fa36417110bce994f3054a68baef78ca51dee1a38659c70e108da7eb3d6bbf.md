Prepare:

1. Install sp1 toolchain v6.4.0: `curl -L https://sp1up.succinct.xyz/ | bash`, then `sp1up -v v6.4.0` (must match the workspace's `sp1-zkvm = "=6.4.0"`).
2. Install docker [https://docs.docker.com/get-started/get-docker/](https://docs.docker.com/get-started/get-docker/)
3. Install just [https://github.com/casey/just](https://github.com/casey/just)

Verify:

1. Checkout the correct tag in [mantle-xyz/op-succinct](https://github.com/mantle-xyz/op-succinct/tree/mantle-v1.6.1) repo: `git checkout mantle-v1.6.1`. Commit hash should be `8d280ded13f3fcba3d85fb6babedaf75cab5e9c0`. This release pins the `revm` crate family to the public [mantle-xyz/revm](https://github.com/mantle-xyz/revm) fork at tag `v107-mantle-arsia.2` and the kona crates to [mantle-xyz/mantle-v2](https://github.com/mantle-xyz/mantle-v2) at tag `mantle-v1.6.3`, so no private dependency is required.
2. Make sure docker is running by running `docker ps`.
3. Delete the committed ELFs so that only freshly built ones can be hashed: `rm elf/aggregation-elf elf/range-elf-embedded`.
4. From the `op-succinct` dir: `just build-elfs`. This checks every tag-pinned git dependency against its remote (`verify-git-pins`) and then rebuilds `programs/range/ethereum` and `programs/aggregation` reproducibly with `cargo prove build --docker --tag v6.4.0` (image `ghcr.io/succinctlabs/sp1:v6.4.0`).
5. From the `op-succinct` dir: `just vkeys` (runs `cargo run --release --bin config` over the rebuilt `elf/*`) and prints the verification key hashes. The `Aggregation Verification Key Hash` printed is this program hash (stored on-chain as `aggregationVkey`). The [mantle-v1.6.1 release notes](https://github.com/mantle-xyz/op-succinct/releases/tag/mantle-v1.6.1) list the expected values.

Reproduced 2026-09-17 on Ubuntu 24.04 (x86_64) with SP1 v6.4.0 (`cargo-prove sp1 (f66b4bf 2026-08-12)`, docker image `ghcr.io/succinctlabs/sp1:v6.4.0`) at commit `8d280ded13f3fcba3d85fb6babedaf75cab5e9c0`. The rebuilt `elf/aggregation-elf` (sha256 `1eb17cad32eae637161f7deb33fa602e9369e553ecaac8dfeee92f30a44c85d1`) is byte-identical to the committed one and hashes to `0x00fa36417110bce994f3054a68baef78ca51dee1a38659c70e108da7eb3d6bbf`, matching `aggregationVkey()` on `OPSuccinctL2OutputOracle` (`eth:0x31d543e7BE1dA6eFDc2206Ef7822879045B9f481`).
