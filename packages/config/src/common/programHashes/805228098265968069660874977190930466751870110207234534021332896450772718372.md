1. Install python (3.9 to 3.13; the pinned `numpy==2.0.2` does not build on Python 3.14) and pip.
2. Install rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`.
3. Checkout the correct version of [https://github.com/starkware-libs/sequencer/tree/main](https://github.com/starkware-libs/sequencer/tree/main): `git checkout APOLLO-0.14.4-RC.8`. Commit hash should be `f1e649f3e131cfbb659aa876b3e946f616dfe6aa`.
4. Install required python dependencies: `python3 -m venv sequencer_venv`, then `. sequencer_venv/bin/activate && pip install -r scripts/requirements.txt`.
5. Run `UPDATE_EXPECT=1 cargo test -p apollo_starknet_os_program test_program_hashes` to regenerate program hashes in `crates/apollo_starknet_os_program/src/program_hash.json`. 
6. To check that this hash is enforced by the L1-registered Starknet OS, confirm it equals `ALLOWED_VIRTUAL_OS_PROGRAM_HASHES_1` in `crates/apollo_starknet_os_program/src/cairo/starkware/starknet/core/os/constants.cairo` (the allowlist has length 2 at this tag, with `ALLOWED_VIRTUAL_OS_PROGRAM_HASHES_0` being the previous virtual OS hash). The Starknet OS only accepts client-side proof facts whose program hash is in this allowlist.
