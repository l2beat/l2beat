# 9. Ossification band wording

Status: accepted, 2026-11-21
Code: `packages/shared-pure/src/utils/ossificationScoreBands.ts`

`OSSIFICATION_BAND_MEANING` says what each band edge means in time. Its
wording follows "which takes" (`good`) and "which means" (`warning`), so every
sentence about the bands is built from it and changes when the bands change.
